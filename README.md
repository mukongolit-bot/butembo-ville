## Présentation du projet
Petit site web qui présente ma ville, Butembo, en 3 photos : le Rond Point Soficom avec le Monument Malu Malu, la Maison Kidubai et le Rond Point VGH, monument historique. Chaque photo a un titre et une description.

## Technologies utilisées
- HTML, CSS
- Cloudinary pour héberger les images
- GitHub + GitHub Pages pour publier le site gratuitement

## Comment Cloudinary est utilisé
1. Je crée un compte gratuit sur cloudinary.com
2. J'uploade mes 3 images dans Media Library
3. Je copie le lien de chaque image (https://res.cloudinary.com/...)
4. Je colle ces liens dans index.html dans les balises <img src="...">
5. Aucune image n'est stockée dans le dépôt GitHub. Le site les charge depuis Cloudinary.

## Comment exécuter le projet localement
1. Télécharger le code
2. Ouvrir index.html dans le navigateur
3. Pas besoin de serveur, pas besoin d'API secret.

## Sécurité
Je ne publie jamais mon API secret Cloudinary. J'utilise seulement les liens publics des images.
